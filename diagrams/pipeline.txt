ERA5 Pipeline — Branch 2 (Stages 1–3)
=====================================

Stage 1 — download_01
---------------------
src/download_01/
    download_era5_single.py
        • Single-variable GRIB downloader (Branch 1 compatibility)
        • Produces:
            - <var>_<year>_<month>.grib
            - <var>_<year>_<month>.grib.<hash>.idx

    download_era5_monthly.py
        • Monthly ZIP + multi-variable GRIB downloader (Branch 2)
        • Produces:
            - era5_<year>_<month>.zip
            - era5_<year>_<month>.grib

    paths.py
        • Stage 1/2-safe Paths class (raw/, metadata/, intermediate/, logs/)


Stage 2 — preprocessing_02
--------------------------
src/preprocessing_02/

    unzip_grib.py
        • Extracts multi-variable GRIB from monthly ZIP
        • Normalizes filenames → era5_<year>_<month>.grib

    inspect_grib.py
        • Unified inspection:
            - Branch 1: full cfgrib open
            - Branch 2: lightweight metadata extraction
        • Returns variable lists, dims, coords, file size

    convert_grib_to_parquet.py
        • Converts BOTH single-variable + multi-variable GRIBs
        • Produces HOURLY Parquet slices
        ↓ intermediate/
            - <grib>_<var>_<timestamp>.parquet

    run_preprocessing.py  (orchestrator)
        Step 1: unzip_all_months()
        Step 2: inspect_all_gribs()
        Step 3: convert_grib_to_parquet()  (parallel)
        Step 4: build_master_metadata()
        ↓ metadata/
            - metadata.json
              {
                "variables": {
                    "<shortName>": { ts: parquet_path }
                },
                "timestamps": [...]
              }


Stage 3 — core_03 (Chunked Parallel Engine)
-------------------------------------------
src/core_03/

    chunk_spec.py
        • Defines chunk boundaries (spatial + temporal)
        • Consumes Stage 2 metadata.json

    chunk_schema.py
        • Defines the schema for chunked Parquet outputs
        • Ensures deterministic structure for Stage 4

    chunk_planner.py
        • Plans chunk execution:
            - which timestamps
            - which variables
            - which spatial tiles
        • Produces a list of ChunkSpec objects

    chunk_worker.py
        • Executes a single chunk:
            - loads hourly Parquet slices
            - applies schema
            - writes chunked Parquet

    chunk_orchestrator.py
        • Main Stage 3 entrypoint
        • Parallel execution of chunk workers
        ↓ core_03_output/
            - chunk_<tile>_<timestamp>.parquet
