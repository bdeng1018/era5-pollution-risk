ERA5 Pipeline — Branch 2 (Stages 1–4 Implemented)
=================================================

Stage 1 — download_01 (GRIB ingestion)
--------------------------------------
src/download_01/

    download_era5_single.py
        • Branch 1 compatibility only (single-variable GRIB)
        • Not used in Branch 2 Makefile

    download_era5_monthly.py
        • Branch 2 monthly ZIP + multi-variable GRIB downloader
        • Produces per-variable GRIBs under:
            data/raw/era5/<year>/<month>/<variable>/
                <variable>_<year>_<month>.grib
                <variable>_<year>_<month>.grib.<hash>.idx

    paths.py
        • Shared path utilities for raw/, metadata/, intermediate/, logs/


Stage 2 — preprocessing_02 (Preprocessing GRIB to Parquet)
----------------------------------------------------------
src/preprocessing_02/

    unzip_grib.py
        • Extracts multi-variable GRIB from monthly ZIP
        • Normalizes filenames → era5_<year>_<month>.grib

    inspect_grib.py
        • Unified inspection:
            - Branch 1: full cfgrib open
            - Branch 2: lightweight metadata extraction
        • Returns variable lists, dims, coords, file size

    convert_grib_to_parquet.py
        • Converts BOTH single-variable + multi-variable GRIBs
        • Produces HOURLY Parquet slices
        ↓ data/intermediate/<year>/<month>/<var>/
            - <grib>_<var>_<timestamp>.parquet

    run_preprocessing.py  (orchestrator)
        Step 1: unzip_all_months()
        Step 2: inspect_all_gribs()
        Step 3: convert_grib_to_parquet()  (parallel)
        Step 4: build_master_metadata()
        ↓ data/metadata/
            - metadata.json
              {
                "variables": {
                    "<shortName>": { ts: parquet_path }
                },
                "timestamps": [...]
              }


Stage 3 — core_03 (Chunked Parallel Engine)
-------------------------------------------
src/core_03/

    chunk_spec.py
        • Defines chunk boundaries (spatial + temporal)
        • Consumes Stage 2 metadata.json

    chunk_schema.py
        • Defines deterministic schema for chunked Parquet outputs
        • Ensures stable structure for Stage 4

    chunk_planner.py
        • Plans chunk execution:
            - timestamps
            - variables
            - spatial tiles
        • Produces list of ChunkSpec objects

    chunk_worker.py
        • Executes a single chunk:
            - loads hourly Parquet slices
            - applies schema
            - writes chunked Parquet

    chunk_merge.py
        • Merges all chunk_<tile>_<timestamp>.parquet into merged.nc
        • Produces merged_metadata.json + merged_qc.json

    chunk_orchestrator.py
        • Main Stage 3 entrypoint
        • Parallel execution of chunk workers
        ↓ data/chunks/
            - chunk_<tile>_<timestamp>.parquet
        ↓ data/chunks_metadata/
            - chunk_<tile>_<timestamp>.json
        ↓ data/intermediate/
            - merged.nc
            - merged_metadata.json
            - merged_qc.json


Stage 4 — spatiotemporal_04 (Compiler Layer)
--------------------------------------------
src/spatiotemporal_04/

    Compiler pass order:
        1. grid
        2. mask
        3. temporal_align
        4. temporal_interpolate
        5. qc
        6. metadata
        7. tensor_builder

    • Produces canonical spatiotemporal tensor
    • Deterministic, pure, import-safe modules
    ↓ data/spatiotemporal/
        - spatiotemporal_tensor.nc
        - stage4_<diagnostic>.json
