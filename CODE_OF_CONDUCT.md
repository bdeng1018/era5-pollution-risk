# Contributor Covenant Code of Conduct - ERA5 Pollution‑Risk Pipeline (Branch 2)

## Our Pledge

We pledge to make participation in this project a harassment‑free, respectful, and inclusive experience for everyone, regardless of:

- age
- body size
- disability
- ethnicity
- gender identity or expression
- experience level
- nationality
- personal appearance
- race
- religion
- sexual identity or orientation

We are committed to fostering an environment where contributors feel safe, supported, and valued.

## Our Standards

### Positive behaviors include

- using welcoming and inclusive language
- respecting differing viewpoints and experiences
- offering constructive feedback
- focusing on what benefits the community and the project
- showing empathy toward other contributors
- maintaining professionalism in all interactions

### Unacceptable behaviors include

- harassment, discrimination, or personal attacks
- trolling, insulting comments, or deliberate provocation
- publishing private information without permission
- disruptive, aggressive, or hostile behavior
- sexualized language, imagery, or unwelcome advances

## Our Responsibilities

Project maintainers are responsible for:

- clarifying standards of acceptable behavior
- taking appropriate action when unacceptable behavior occurs
- moderating, editing, or rejecting contributions that violate this Code of Conduct
- temporarily or permanently banning contributors for severe or repeated violations

## Scope

This Code of Conduct applies to:

- all project spaces
- GitHub issues, pull requests, discussions, and reviews
- project documentation and communication channels
- any public or private communication related to the project
